DepotDownloader notice
======================

Team Frontress does not distribute DepotDownloader. On first use, the open
source tf2-content-helper downloads the official, unmodified macOS x64 archive
for DepotDownloader 3.4.0 directly from the SteamRE GitHub release into the
user's Team Frontress Application Support directory. It verifies the archive
and executable against SHA-256 values pinned in tf2-content-helper.swift before
executing it. Team Frontress does not link against DepotDownloader.
